# 出口、制裁、加密与远程控制提示

**版本：** 2026-10-24  
**重要：** 本文不是法律意见，也不是出口分类结论。

---

## 1. 为什么需要关注

本项目包含：

```text
网络通信（TCP/TLS/mTLS）
认证与 token
远程设备控制（host bridge）
桌面/输入/文件访问
加密库使用
可能被用于监控/自动化的能力
```

不同司法辖区可能对：

```text
加密软件
入侵/监控工具
远程控制软件
出口/再出口
制裁地区/主体
最终用途（军事/情报/执法）
```

有登记、许可、禁运或最终用户审查要求。

## 2. 你需要自己确认

```text
你是否在受制裁国家/地区
你是否在出口管制名单上
最终用户/最终用途是否受限
是否涉及军事、情报、警务、关键基础设施
是否需要加密登记/许可
是否需要当地网络安全/计算机犯罪法审查
```

## 3. 不提供的保证

维护者不声明：

```text
本项目属于哪个出口分类
可以在任何国家合法使用
可以用于任何行业
可以用于监控/执法/军事
```

## 4. 建议

```text
商用/政府/国防相关使用前咨询出口律师
不要向受制裁主体提供下载/支持
保留最终用户/用途记录（如适用）
关注依赖库的加密/出口条款
```

本文只提示风险，不构成出口/制裁/加密合规结论。
