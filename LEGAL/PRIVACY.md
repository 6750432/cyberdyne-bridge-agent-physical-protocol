# Privacy / 隐私说明

**版本：** 2026-10-24  
**范围：** 本项目静态网站 + 本地软件，不覆盖第三方 GitHub、模型 API、游戏服务器。

---

## 1. 网站

本站是 GitHub Pages 上的静态站点：

```text
https://www.cyberdyne-bridge.com/
https://www.cyberdyne-bridge.com/legal.html
```

当前站点：

```text
没有自建账号系统
没有自建评论
没有自建广告
没有自建分析脚本
没有 Cookie 同意弹窗（因为没有设置非必要 Cookie）
没有把本地 CBAP 服务暴露到网页
```

GitHub Pages / GitHub 可能按其自身政策处理访问日志、IP、User-Agent 等。
请阅读 GitHub 的隐私声明。维护者不控制 GitHub 的日志。

## 2. 软件

CBAP 软件默认在本地运行。维护者不收集：

```text
你的设备文件
你的屏幕截图
你的键鼠输入
你的 Minecraft 账号
你的模型 prompt
你的 token
你的审计日志
```

但软件可能在你的机器上产生：

```text
/tmp/cbap-*
logs/cbap-audit.jsonl
CBAP OS 测试文件
测试截图
```

这些数据由你控制；你需要自行清理、保护和备份。

## 3. 模型 / 第三方服务

如果你把 prompt、截图、文件内容或设备状态发送给第三方模型/API：

```text
该第三方按其条款处理数据
维护者不控制其保留、训练或跨境传输
你需要自行取得必要的同意/授权
不要把秘密、个人信息或他人数据发给未审查的模型
```

## 4. 安全报告

通过 GitHub Security Advisory 提交的报告会按 GitHub 的机制处理。  
请不要在公开 Issue 中提交：

```text
真实 token / 私钥
身份证号 / 手机号 / 邮箱
他人设备截图
未脱敏日志
```

## 5. 儿童 / 未成年人

本项目不是面向儿童的产品。未成年人使用需监护人知情同意，并遵守当地法律和
游戏服务条款。

## 6. 数据主体权利

如果你部署本项目并处理他人个人数据，你是该部署的数据控制者/处理者，需自行：

```text
提供隐私通知
建立合法处理基础
处理访问/更正/删除请求
进行跨境传输评估（如适用）
保存处理记录（如适用）
```

维护者不替你的部署承担这些义务。

## 7. 保留期限

维护者不通过本项目集中收集数据，因此没有统一的集中保留期限。  
你本地产生的日志/截图由你决定保留多久。

## 8. 第三方链接

本站链接到 GitHub、Mojang/Microsoft、DeepSeek、Qwen、Mindcraft、Voyager 等第三方。
这些站点有自己的隐私政策。

## 9. 变更

本说明可能更新。重大变化会在仓库/Release 中注明。

## 10. 联系

隐私问题请通过仓库 Issue 提出，且不要包含敏感个人信息。  
安全问题请走私密渠道 [`SECURITY.md`](../SECURITY.md)。

## 11. 不是法律意见

本说明是透明度披露，不是针对你的部署的法律合规方案。  
商用、处理敏感数据、面向欧盟/中国等地区用户时，请咨询律师/隐私顾问。
