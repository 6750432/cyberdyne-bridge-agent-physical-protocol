# AI Disclosure / AI 辅助披露

**版本：** 2026-10-24

## 1. 哪些部分有 AI 参与

本项目有大量 AI 辅助生成/修改的内容，可能包括：

```text
Kernel / driver / test 代码
文档与图表
测试用例
提交信息
安全说明草稿
本法律目录的初稿
```

人类维护者负责：

```text
架构与边界
安全红线和验收
代码合并决定
发布决定
```

但人类审阅不等于对正确性、安全性或法律合规的担保。

## 2. AI 输出不是事实

AI 可能：

```text
编造 API
写错边界条件
遗漏威胁
产生不安全默认值
引用不存在的法律/案例
```

任何安全/法律文本都必须由人类和（必要时）律师复核。  
本项目中的法律文件是工程草稿，不是律师意见。

## 3. 模型和训练数据

本项目不分发模型权重。  
如果你接入 DeepSeek、Qwen 或其他模型，需遵守其模型许可/服务条款。

模型输出可能包含第三方内容；你需要自行判断版权、隐私和准确性。

## 4. Prompt injection

Agent 读取的网页、聊天、文件、MCP 工具输出都可能包含恶意指令。  
不要把模型输出当作可信系统指令；权限必须由 Kernel/policy 决定，而不是 prompt。

## 5. 责任

使用 AI 产生的动作、成本、错误和后果由使用者承担。  
维护者不保证 AI 行为符合你的意图、法律或行业标准。

## 6. 披露建议

如果你分发本项目或其修改版，建议保留本披露，并注明：

```text
哪些部分由 AI 辅助
人类做了哪些审阅
有哪些已知限制
```
