# Acceptable Use Policy / 可接受使用政策

**版本：** 2026-10-24  
**重要：** 这是项目政策草稿，不是法律意见。维护者可以更新政策，但不承诺逐一通知。

---

## 1. 总原则

本项目只用于：

```text
你拥有或明确获授权的设备、账号、服务器、网络和数据
合法的研究、教学、测试和个人自动化
遵守游戏 EULA、服务器规则和第三方服务条款
尊重他人隐私、财产和人身安全
```

**技术能力不是授权。**  
你能打开 `host://fs`，不代表你有权读那台机器上的文件；你能打开
`host://input/keyboard`，不代表你有权在别人机器上输入。

## 2. 绝对禁止

```text
未经授权访问、控制、扫描或干扰他人设备/账号/网络
开发、分发或使用恶意软件、勒索软件、间谍软件、键盘记录器
窃取凭证、Cookie、token、私钥、聊天记录、屏幕或文件
绕过认证、访问控制、反作弊、DRM 或安全机制
在公共 Minecraft 服务器或他人服务器上违反规则自动化
骚扰、跟踪、威胁、人肉、歧视、欺诈、诈骗
破坏他人建筑、账号、存档、游戏体验或商业服务
把 host bridge 暴露到公网或卖给未授权使用者
使用本项目进行现实世界的物理伤害、监视或控制
违反出口管制、制裁、隐私法、计算机犯罪法或当地法律
```

## 3. Minecraft / 游戏场景

允许（在你拥有或获授权的环境）：

```text
本地单机
你自己的局域网私服
经服主明确同意的测试服
AI/Agent 协议研究
离线实验
```

禁止：

```text
Hypixel、2B2T 等公共服务器上的自动化/反作弊规避
用无头客户端刷资源、刷成就、代练、搬砖
恶意 PVP、屠杀、破坏他人建筑
绕过服务器白名单、封禁或反作弊
把自动化能力包装成“外挂”分发
```

账号封禁、IP 封禁、存档丢失、服务端处罚由使用者承担。

## 4. Host / 桌面 / 文件 / 输入

允许：

```text
在你自己的隔离测试机上
绑定 127.0.0.1
使用 allowlist 测试目录
在明确同意后用输入设备做演示
演示结束立即停止 bridge
```

禁止：

```text
把 host bridge 绑到 0.0.0.0 / 公网 / 共享网络
在他人电脑上启用鼠标键盘
在用户不知情时截屏、录屏、读文件
采集密码、支付信息、身份证件、私人聊天
在共享/多用户系统上绕过系统权限
把测试 token 当生产密钥
在没有 kill switch 的情况下长时间无人值守
```

## 5. AI / Agent 场景

你必须：

```text
给 Agent 最小权限
使用默认拒绝
设置 rate limit / max_bytes / max_inflight
保留审计
设置急停
对高风险动作要求人工审批
不要让 Agent 自己修改安全策略
不要让 Agent 自己决定是否越过 allowlist
```

你不应：

```text
把 root shell 直接交给模型
把整个 home 暴露给模型
让模型自行安装/升级安全组件
让模型在无人监督下控制真实工业/医疗/交通设备
用 prompt 代替权限系统
```

见 [`ABUSE.md`](ABUSE.md) 和 [`SECURITY.md`](../SECURITY.md)。

```text

删除维护者控制范围内的内容/链接
拒绝支持
向平台报告
向执法机构报告
```

维护者不保证监控所有使用，也不对第三方滥用行为承担替代责任。

## 8. 举报者保护

善意安全研究、隐私报告和滥用报告不应被报复。  
请只测试你拥有或获授权的环境，不要访问/泄露他人数据或造成服务中断。

## 9. 不是法律意见

本政策不构成法律建议，也不替代你所在司法辖区的法律、游戏 EULA 或服务器规则。
