# Abuse / 滥用报告与处置

**版本：** 2026-10-24

---

## 1. 什么算滥用

```text
未经授权控制他人设备/账号
把 CBAP 用作远控木马/后门/间谍软件
窃取凭证、屏幕、文件、聊天记录
在公共服务器上违反规则自动化
绕过反作弊/访问控制
骚扰、跟踪、威胁、人肉
分发外挂/恶意修改版
把 host bridge 暴露到公网供他人使用
冒充官方项目/维护者
```

## 2. 怎么报告

优先走私密渠道：

```text
https://github.com/cyberdyne-bridge/cyberdyne-bridge-agent-physical-protocol/security/advisories/new
```

如果入口不可用，开一个**不含敏感细节**的 Issue，标题注明：

```text
[ABUSE] 需要私密渠道
```

提供：

```text
发生了什么
涉及哪个仓库/版本/链接
是否涉及真实设备/账号/数据
是否有人身安全风险
你希望的处理方式
可公开的时间线
```

**不要**在公开 Issue 贴：

```text
token、私钥、密码
身份证、手机号、邮箱
他人设备截图
未脱敏日志
完整攻击链
```

## 3. 紧急情况

如果存在即时人身危险、正在进行的入侵、勒索或儿童安全风险：

```text
先联系当地紧急服务/执法机构
保留证据
再通知维护者
```

维护者不是应急服务，不能保证实时响应。

## 4. 维护者可以做什么

在适用法律和平台规则允许范围内：

```text
要求停止
删除维护者控制的仓库内容/链接/Release
拒绝支持
发布安全公告
向 GitHub/平台报告
向执法机构报告
限制维护者控制的访问
```

维护者**没有义务**监控全网使用，也不保证对每个报告采取特定行动。

## 5. 对修改版/分发的处理

如果有人分发修改版并滥用：

```text
维护者可以公开澄清与其无关
可以要求移除官方名称/logo
可以依据 LICENSE 处理版权/商标问题
但不能替代平台/执法机构对第三方行为的处理
```

## 6. 下架 / 版权投诉

如果你认为仓库内容侵犯你的版权/商标/隐私：

```text
通过 GitHub 的 DMCA/隐私/商标流程提交
同时给维护者一个不含敏感细节的通知
提供权属证明、具体 URL、请求动作
```

维护者会在合理范围内处理，但不构成法律意见。

## 7. 善意研究保护

维护者支持善意安全研究。请：

```text
只测试你拥有或获授权的环境
不访问/修改/泄露他人数据
不造成服务中断
给修复留合理时间
```

## 8. 记录

维护者可能保留与滥用报告相关的必要记录，用于安全、法律和平台申诉。
不要在报告中发送不必要的个人数据。

## 9. 不是法律意见

本流程不是法律建议，也不保证任何特定结果。
