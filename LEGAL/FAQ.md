# Legal FAQ / 法律常见问题

**不是法律意见。** 具体问题请咨询律师。

## 这是远控木马吗？

不是。CBAP 是设备协议/参考实现，host bridge 是本地测试设施，默认只应绑定
`127.0.0.1`，输入默认关闭。  
但任何具备远程控制能力的软件都可能被滥用；所以我们有 AUP、默认拒绝和边界说明。

## 能在公共 Minecraft 服务器用吗？

不建议，通常也违反服务器规则。项目明确禁止在公共服务器上规避反作弊或破坏
他人体验。账号封禁/处罚由使用者承担。

## 能商用吗？

原创代码是 MIT，允许商用；但：

```text
第三方 GPL 补丁/依赖必须单独合规
Minecraft/模型/平台条款仍需遵守
高风险行业需要额外法律/安全审查
```

商用前请律师审阅 [`TERMS.md`](TERMS.md) 和 [`COUNSEL-CHECKLIST.md`](COUNSEL-CHECKLIST.md)。

## 能把 host bridge 开到公网吗？

不要。默认只绑 loopback；公网暴露会把它变成高风险远程控制入口。  
即使加 TLS/token，也不等于可以未经授权控制他人设备。

## 项目收集我的数据吗？

维护者不通过软件集中收集。网站是静态 GitHub Pages，没有自建分析。  
GitHub 可能按自己的政策记录访问日志。本地日志/截图由你控制。

## 我的日志里有个人信息怎么办？

不要提交到公开仓库。使用 `.gitignore`、脱敏、私有备份。  
如果已经 push，普通删除不会从历史消失；需要 history rewrite 或新建干净仓库。

## 为什么有 GPL？

只有 `mineflayer-mcp` 的兼容补丁是 GPL-3.0；它不是 MIT 核心。  
详见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。

## 发现漏洞/滥用怎么办？

安全漏洞：走私密 Security Advisory。  
滥用：见 [`ABUSE.md`](ABUSE.md)。  
不要在公开 Issue 贴 token、私钥、他人数据或完整攻击链。

## 这些法律文件能保护我吗？

它们能降低误解和风险，但**不能替代律师**，也不能保证在任何司法辖区可执行。
商用/发行/提供服务前请做正式法律审查。
