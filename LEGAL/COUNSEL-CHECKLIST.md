# Counsel Review Checklist / 律师审阅清单

**用途：** 给律师的 intake 清单，不是法律意见。  
**项目：** Cyberdyne Bridge / CBAP

---

## 1. 主体与运营

```text
谁运营仓库/网站？
个人、公司还是基金会？
服务器/域名/GitHub 组织在哪个司法辖区？
是否有雇员/承包商/贡献者？
是否接受赞助/广告/商业支持？
```

## 2. 许可证

```text
根 MIT 是否满足商业模式？
GPL-3.0 mineflayer-mcp patch 是否与分发方式兼容？
是否把 GPL 代码与闭源代码组合？
是否通过网络提供服务（可能的 AGPL/网络服务问题）？
第三方 MIT notice 是否完整？
上游 patch 的版权/许可是否准确？
```

## 3. 条款可执行性

```text
责任限制在目标司法辖区是否可执行？
消费者/未成年人是否排除？
赔偿条款是否可执行？
管辖/仲裁条款是否需要补充？
是否需要中文/英文双语版本？
是否需要“最后更新”/用户同意机制？
```

## 4. 隐私

```text
网站是否收集 IP/Cookie/分析数据？
GitHub Pages 日志如何处理？
部署者是否处理个人信息？
PIPL/GDPR/CCPA 是否适用？
是否需要隐私通知/DPA/跨境传输机制？
```

## 5. 游戏/第三方平台

```text
Minecraft EULA/商业使用政策
服务器规则/反作弊
Mojang/Microsoft/网易商标
DeepSeek/Qwen 模型条款
MCP/上游项目条款
GitHub/B站平台规则
```

## 6. 高风险用途

```text
医疗/工业/交通/关键基础设施
监控/执法/军事
未成年人
远程控制他人设备
出口/制裁
```

## 7. 滥用与执法

```text
滥用报告流程
下架/DMCA/隐私投诉
执法请求处理
日志保留
保险（网络/媒体责任）
```

## 8. 交付物

```text
审阅后的 TERMS.md
审阅后的 PRIVACY.md
审阅后的 ACCEPTABLE-USE.md
审阅后的 DISCLAIMER.md
许可证合规意见
出口/制裁意见（如适用）
```
