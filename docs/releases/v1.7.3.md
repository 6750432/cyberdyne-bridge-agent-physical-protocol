# v1.7.3 — Technical Hardening

## 内容

```text
host bridge 默认随机 token
不再把 token 打印到 status / stdout
token 文件 <socket>.token，mode 0600
Kernel 默认拒绝非 loopback TCP bind
host bridge 非 loopback 必须显式 --allow-public
裸 X11 输入必须显式 --allow-unisolated-input
输入推荐 --input-backend portal --require-isolated-input
host bridge status 文件 0600 / 原子写入
新增 hardening tests
```

## 验证

```text
CBAP conformance: 118/118
非 loopback bind: refused by default
裸 X11 input: refused by default
status 不再包含 token
```

## 使用

```bash
python3 tools/cbap_host_bridge.py \
  --root ~/Desktop/CBAP-Host-Test \
  --tcp-port 18765
# token 在 <socket>.token，不在 stdout/status

python3 tools/cbap_host_bridge.py \
  --root ~/Desktop/CBAP-Host-Test \
  --tcp-port 18765 \
  --enable-input --input-backend portal --require-isolated-input
```

生产/公网仍需额外网络层、TLS/mTLS、密钥管理和法律审查；这些改动只是
减少默认滥用面。
