# v1.6.0 — Host Device Surface

## 内容

```text
host://desktop         filesystem compatibility API
host://fs              allowlisted filesystem
host://display         Wayland screenshot into allowlist
host://input/mouse     opt-in X11/XWayland pointer
host://input/keyboard  opt-in X11/XWayland keyboard
```

这些是真实的 CBAP device_id，进入 Kernel welcome `devices` 列表，并按设备
分别拥有 lease / safety / estop 状态。

## 安全边界

```text
display 只写 allowlist 内的 PNG
mouse/keyboard 默认关闭
--enable-input 才打开 X11/XWayland 注入
没有 native Wayland 键鼠注入
没有 shell
filesystem 仍是 allowlist，不是宿主根目录
input 是本地测试原型，不是生产远程控制
```

见 `docs/CBAP-OS-Host-Bridge.md`。
