01 / WHAT IT IS

不是「会玩 MC 的脚本」，
是协议层。

我们想验证的东西与 Minecraft 无关：一个 Agent 要在信息不完整、动作有代价、环境会变的世界里可靠地干活，需要什么样的接口与判据。

01

完成判据看事实

手说「发出去了」不算数；背包里真多出那个掉落物，才算挖到。

02

fail-closed，不许静默

听不懂、拿不准、参数缺，就拒绝执行、记账、出声。吞异常比崩溃更难查。

03

加能力，不碰主链

新能力做成可热插拔车厢：manifest + 补丁 + 宪法体检。过不了，就拒绝起车。

02 / ARCHITECTURE

反射在脑下面。

Python 脑 + Node 手，Unix Domain Socket 通信。云端 LLM 负责规划，本地规则负责拒绝。

03 / PROTOCOL NOTES

每一条，
都带着踩坑记录。

不是设计模式合集，是被现实打回来之后留下的判据。

  1. 01

    完成判据看事实，不看回执

    手说「发出去了」不算数；背包里真多出那个掉落物，才算挖到。

  2. 02

    fail-closed，且不许静默

    听不懂、拿不准、参数缺 ⇒ 拒绝执行 + 记账 + 出声。吞异常比崩溃更难查。

  3. 03

    坐标只能来自证据

    不猜、不用 or [0,0,0] 兜底；有专门的审计器在扫这件事。

  4. 04

    自愈最小侵入

    挡路了就地插一步，绝不把正在跑的计划整条作废。

  5. 05

    记忆能被现实否掉

    挖过账 + 重启读回过去 5 分钟的方块变化；记错就改，不硬撑。

04 / CURRENT STATE

它能做到，
也经常卡住。

2026-10-10 凌晨，清空记忆、只带 64 块食物，从空手第一次独立走到石镐。

从空手到石镐

砍树→木板→工作台→木镐→向下挖→石镐

它仍然会走冤枉路、重复失败，需要人读日志找真根。这个仓库最诚实的部分之一，是 docs/日志摘录/ 里那些失败的账。

还没做

  • 多人协作
  • 跨 Agent 通信
  • 性能优化
  • 第二沙盒

不假装已经完成。

05 / CARRIAGES

26 节车厢，
随时挂，随时摘。

每节车厢一个目录：manifest.json + 补丁.py + 测试。起车做宪法体检，过不了就拒绝起车。

26当前编组
1–7ms实测换轨
1条 Unix Socket
2进程：脑 + 手
核心

生存常识

常识库 + 求解器接线：落坐标 / 找坐标 / 向下盲挖 / 就地插步。

记忆

记性

自己放的记下来、挖过账、换木种、合成前补料、重启预热。

采集

收集

把「挖一步 / 拾一步」收成一条命令，支持成批收集与落坐标。

自愈

障碍 / 够不着

挡路、够不着，就地插一步；不作废整条计划。

体检

物理体检

假活、可达性、视线与距离检查；在动作前先问物理世界。

观测

自我模型

只读 predicted vs actual、每步体检、step 回执与 plan revision。
